# Документация SupportFlow

В этой папке хранится документация, которая подробнее корневого README описывает продукт, архитектуру и принятые технические решения.

## Содержание

### Продукт

### Архитектура

- [Модули и правила зависимостей](architecture/modules.md) — ответственность модулей и допустимые направления ссылок.

### Архитектурные решения

- [ADR-0001: использовать модульный монолит](adr/0001-use-modular-monolith.md).
- [ADR-0002: разделить владение данными по модулям](adr/0002-use-module-owned-dbcontexts.md).

## Правила ведения

- Документ создаётся, когда появляется реальное требование или принятое решение.
- README содержит обзор, а подробности размещаются в соответствующем разделе `docs`.
- Принятое архитектурное решение не переписывается задним числом. При его изменении создаётся новый ADR, который заменяет предыдущий.
- Документация обновляется в том же commit, что и связанное изменение поведения или архитектуры.
