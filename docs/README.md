## Правила ведения

- Документ создаётся, когда появляется реальное требование или принятое решение.
- README содержит обзор, а подробности размещаются в соответствующем разделе `docs`.
- Принятое архитектурное решение не переписывается задним числом. При его изменении создаётся новый ADR, который заменяет предыдущий.
- Документация обновляется в том же commit, что и связанное изменение поведения или архитектуры.
